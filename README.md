# زخرف — معرض اللوحات

موقع لمتجر **زخرف** يعرض اللوحات في ممر معرض ثلاثي الأبعاد: تمشي فيه بالسكرول، ولما تضغط على أي لوحة الكاميرا تلتفت لها وتظهر بياناتها وزر الطلب.

## المكتبات
- [GSAP + ScrollTrigger](https://gsap.com) — حركة الكاميرا والإنترو وتلاشي الواجهة
- [Lenis](https://github.com/darkroomengineering/lenis) — سكرول ناعم
- الممر نفسه مبني بـ CSS 3D (بدون WebGL) عشان يكون خفيف

## التعديل
كل الإعدادات في أول السكريبت داخل `index.html`:

- `WHATSAPP` — رقم واتساب المتجر بالصيغة الدولية بدون `+` (مثال: `9665xxxxxxxx`)
- `RAW` — قائمة اللوحات: الاسم، الأسلوب، الألوان، النسبة، المقاس، التقنية، السعر، لون البرواز
- لاستخدام صورة حقيقية للوحة: `ART[i].img = 'images/painting-1.webp'`

اللوحات والأسعار الحالية نماذج للعرض فقط.

## التشغيل محلياً
افتح `index.html` في المتصفح، أو:

```bash
npx serve .
```
